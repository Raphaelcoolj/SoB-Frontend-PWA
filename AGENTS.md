# SoB Frontend — Agent Quick Reference

## Stack
- **Framework**: Next.js (App Router, canary)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State**: Zustand (`src/store/authStore.ts`)
- **Data Fetching**: SWR + SWR Infinite (hooks in `src/hooks/`)
- **Real-time**: Socket.IO client (`src/lib/socket.ts`)
- **Icons**: Lucide React
- **Auth**: JWT tokens stored in Zustand + localStorage

## Key Conventions

### Imports
- Use `../../../` relative paths (not `@/` aliases) — this project uses relative imports
- Exception: `fetchWithAuth` from `../../lib/api` (relative)

### Component Patterns
- All components use `'use client'` directive (this is a client-rendered app)
- Components use `interface` for props, exported as default or named
- Memo: `ArticleCard` and `PostCard` use `export default memo(Component)` for perf

### Post Card Variants
- **`variant="flat"`**: Twitter-style, used in feeds (border-b, no card bg, avatar on left)
- **`variant="default"`**: Card style, used in post detail and standalone views

### PostFeed Props
```typescript
interface PostFeedProps {
  posts: Post[];
  isLoadingInitial: boolean;
  isLoadingMore: boolean;
  hasMore: boolean;
  isEmpty: boolean;
  loadMore: () => void;
  variant?: 'default' | 'flat';
}
```

### Data Fetching
- **`fetchWithAuth(endpoint, options)`** wraps all API calls
- Automatically adds `Authorization: Bearer <token>` from authStore
- On 401, attempts refresh; if fails, redirects to `/login`
- **SWR hooks** for caching/dedup: `useSWR(key, fetcher, options)`
- **SWR Infinite** for paginated feeds: `useSWRInfinite(getKey, fetcher)`

### TrendingSection
- Uses `useSWR('/api/feed/trending', fetcher)` with 60s dedup interval
- Renders horizontal scroll (`overflow-x-auto`, `snap-x snap-mandatory`)
- Shows: cover image, field badge, title, author avatar, uniqueViews, avgReadTimeSeconds
- CSS: `.scrollbar-hide::-webkit-scrollbar { display: none }` via `<style jsx global>`
- Returns null if no trending articles

### Types
- **Post**: `_id`, `author: User`, `contentType: 'article'|'post'`, `title?`, `body`, `mediaUrls[]`, `field: string|Field`, `likes: string[]`, `impressions`, `createdAt`
- **User**: `_id`, `name`, `username`, `avatar?`, `bio?`, `priorityFields`
- **Field**: `_id`, `name`, `slug`

### State Management
- Zustand store at `src/store/authStore.ts`
- Stores: `user`, `accessToken`, `refreshToken`
- Actions: `setAuth(user, accessToken, refreshToken)`, `setTokens(at, rt)`, `clearAuth()`, `updateUser(data)`

### API Endpoints Used
- `GET /api/feed/fyf?cursor=0&type=article|post` — For You feed
- `GET /api/feed/following?cursor=0` — Following feed
- `GET /api/feed/trending` — Trending articles
- `GET /api/posts/:id` — Post detail (increments views)
- `POST /api/posts/:id/read-time` — Submit read time `{ seconds }`
- `POST /api/posts/:id/like` — Toggle like
- `POST /api/posts/:id/bookmark` — Toggle bookmark
- `GET /api/users/mentions/search?q=` — Mention autocomplete

### Mention System
- **MentionTextarea** (`src/components/shared/MentionTextarea.tsx`) — textarea with built-in `@` autocomplete; debounced search against `/api/users/mentions/search`, dropdown with avatar+name+username, keyboard navigation (arrows/enter/escape)
- **MentionText** (`src/components/shared/MentionText.tsx`) — renders `@username` as clickable `<Link>` to `/profile/:username` with accent color; used in PostCard (feed + detail), ArticleCard, CommentCard
- Integrated into create post page, edit post page (post mode), and CommentSection textarea
- Backend parses `@username` and post-link mentions on creation, fires `mention` notifications

### PWA / Viewport
- Root `layout.tsx` exports a `Viewport` with `userScalable: false`, `maximumScale: 1` to prevent pinch-zoom on PWA
- Also includes a `<meta>` tag fallback with `user-scalable=no, maximum-scale=1`

### Admin Pages
- All admin pages (`admin/dashboard`, `admin/feedback`, `admin/pipeline`) use responsive padding (`p-4 sm:p-6`), responsive heading sizes (`text-2xl sm:text-3xl`), and `min-w-0` with `truncate` to prevent overflow on mobile
- Admin layout has a mobile hamburger menu and `overflow-x-hidden` on the main content area
- Tab buttons in the pipeline page use `flex-wrap` to wrap on small screens
